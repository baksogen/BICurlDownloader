API Reference

Complete API Documentation for BICurlDownloader

BIDownloadManager

Main download manager singleton class for managing all downloads.

Instance

Property Type Description
shared BIDownloadManager Singleton instance

Methods

Method Description
configure(_:) Configure manager with custom settings
download(url:destinationPath:options:) Create and start a download task
download(url:destinationPath:options:note:) Create download task with custom note
quickDownload(from:to:completion:) Quick download with completion handler
pauseAll() Pause all active downloads
resumeAll() Resume all paused downloads
cancelAll() Cancel all downloads
getActiveTasks() Get currently downloading tasks
getQueuedTasks() Get tasks waiting in queue
getAllTasks() Get all tasks
getTask(byId:) Find task by ID
getTasks(forURL:) Find tasks by URL
getTasks(withNote:) Find tasks by note
checkBackgroundAudioAvailability() Check background download capability
getDownloadStatistics() Get download statistics

BIAuthenticationOptions

Authentication configuration for downloads.

Initializers

Method Description
init(basicWithUsername:password:) Create Basic authentication
init(digestWithUsername:password:) Create Digest authentication
init(bearerToken:) Create Bearer token authentication
init(customWithHeader:value:) Create custom header authentication

Example

// Basic Auth
let auth = BIAuthenticationOptions(
    basicWithUsername: "user",
    password: "password"
)

// Bearer Token
let auth = BIAuthenticationOptions(
    bearerToken: "your_token_here"
)

// Custom Header
let auth = BIAuthenticationOptions(
    customWithHeader: "X-API-Key",
    value: "your_api_key"
)

BIDownloadDelegate

Protocol for receiving download events.

Methods

Method Description
downloadDidStart(_:) Called when download starts
downloadDidProgress(_:progress:) Called with progress updates (0.0 to 1.0)
downloadDidComplete(_:filePath:) Called when download completes
downloadDidFail(_:error:) Called when download fails

Example Implementation

// Swift
extension MyClass: BIDownloadDelegate {
    func downloadDidStart(_ task: BIDownloadTask) {
        print("Started: \(task.id)")
    }
    
    func downloadDidProgress(_ task: BIDownloadTask, progress: Double) {
        print("Progress: \(Int(progress * 100))%")
    }
    
    func downloadDidComplete(_ task: BIDownloadTask, filePath: String) {
        print("Completed: \(filePath)")
    }
    
    func downloadDidFail(_ task: BIDownloadTask, error: Error) {
        print("Failed: \(error)")
    }
}

// Objective-C
@interface MyClass : NSObject <BIDownloadDelegate>
@end

@implementation MyClass

- (void)downloadDidStart:(BIDownloadTask *)task {
    NSLog(@"Started: %@", task.taskId);
}

- (void)downloadDidProgress:(BIDownloadTask *)task progress:(double)progress {
    NSLog(@"Progress: %ld%%", (long)(progress * 100));
}

- (void)downloadDidComplete:(BIDownloadTask *)task filePath:(NSString *)filePath {
    NSLog(@"Completed: %@", filePath);
}

- (void)downloadDidFail:(BIDownloadTask *)task error:(NSError *)error {
    NSLog(@"Failed: %@", error);
}

@end
