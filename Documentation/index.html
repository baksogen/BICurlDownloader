BICurlDownloader Framework

Complete Documentation for iOS Download Framework

Welcome

BICurlDownloader is a powerful iOS framework for file downloads with support for multipart downloading, background downloads, authentication, and more.

✅ System libcurl

Fast and reliable downloads using system libcurl

✅ Multipart Downloads

Automatic file splitting for faster downloads

✅ Background Downloads

Continue downloads when app is in background

✅ Resume Support

Resume interrupted downloads from where they stopped

✅ Authentication

Support for Basic, Digest, Bearer, and Custom auth

✅ Download Queue

Manage multiple downloads with priority

✅ Progress Monitoring

Detailed information about download state

✅ Swift & Objective-C

Full compatibility with both languages

Key Features

Download Management

  • Start, pause, resume, and cancel downloads
  • Monitor download progress in real-time
  • Download queue with priority management
  • Limit concurrent downloads
  • Download speed throttling
  • Custom HTTP headers support

Background Operations

  • Works alongside existing app audio session
  • Programmatically generated silent audio playback
  • Automatic audio lifecycle management
  • Audio session interruption handling
  • Mixing support with main app audio

Network Features

  • HTTP Range requests support detection
  • Server capabilities validation
  • Network quality monitoring
  • Automatic retry with exponential backoff
  • SSL/TLS verification
