Background Download

Keep downloads running when app is backgrounded

Overview

BICurlDownloader supports background downloads using programmatically generated silent audio. When your app enters the background, the framework can continue downloads by playing inaudible audio, keeping the app active.

How it works:
The framework generates silent audio at ~20 Hz (below human hearing) with near-zero amplitude. This allows the app to remain active in the background using the audio background mode, enabling downloads to continue.

Project Setup

To enable background downloads, you must add the Background Modes capability to your app.

Step 1: Add Background Modes Capability

  1. Open your project in Xcode
  2. Select your app target
  3. Go to the Signing & Capabilities tab
  4. Click + Capability button
  5. Search for and add Background Modes
  6. Enable Audio, AirPlay, and Picture in Picture

Step 2: Verify Info.plist

Xcode automatically adds the required keys to your Info.plist. Verify it contains:

<key>UIBackgroundModes</key>
<array>
    <string>audio</string>
</array>

Step 3: Check Capability

Verify that background audio is available:

Swift

let manager = BIDownloadManager.shared
let isAvailable = manager.checkBackgroundAudioAvailability()

if isAvailable {
    print("Background downloads are available")
} else {
    print("Background downloads are NOT available")
    
    // Get detailed info
    let info = manager.getBackgroundAudioCapabilityInfo()
    if let reason = info.reason {
        print("Reason: \(reason)")
    }
}

Objective-C

BIDownloadManager *manager = [BIDownloadManager shared];
BOOL isAvailable = [manager checkBackgroundAudioAvailability];

if (isAvailable) {
    NSLog(@"Background downloads are available");
} else {
    NSLog(@"Background downloads are NOT available");
}

Using Background Downloads

Enable for Download Task

Background audio is enabled by default. To explicitly control it:

Swift

var options = BIDownloadOptions()
options.enableBackgroundAudio = true  // Default is true

let task = manager.download(
    url: url,
    destinationPath: path,
    options: options
)

Objective-C

BIDownloadOptions *options = [[BIDownloadOptions alloc] init];
options.enableBackgroundAudio = YES;  // Default is YES

BIDownloadTask *task = [manager downloadFromURL:url
                                destinationPath:path
                                        options:options];

Automatic Activation

The framework automatically manages background audio:

  • Audio starts when app enters background with active downloads
  • Audio stops when app returns to foreground
  • Audio stops when all downloads complete or are paused
  • Audio pauses during phone calls and resumes after

Audio Session Management

Mixing with App Audio

BICurlDownloader uses AVAudioSessionCategoryOptionMixWithOthers to allow background downloads alongside your app's audio playback.

Example: Music Player App

// Your app's audio configuration
let audioSession = AVAudioSession.sharedInstance()
try? audioSession.setCategory(
    .playback,
    mode: .default,
    options: [.mixWithOthers]
)

// BICurlDownloader's silent audio will mix with your playback
// Downloads continue while music plays in background

Handling Interruptions

The framework handles audio interruptions automatically:

  • Phone Calls - Silent audio pauses, resumes after call ends
  • Alarms - Silent audio pauses during alarm, resumes after
  • Siri - Silent audio pauses, resumes when Siri completes
  • Other Apps - Respects audio session priority
// The framework monitors interruptions internally
// Downloads pause during interruption and resume automatically
// No additional code needed

Technical Details

Silent Audio Specifications

Parameter Value Reason
Frequency ~20 Hz Below human hearing range (20-20,000 Hz)
Amplitude Near zero Imperceptible to users
Format PCM 16-bit stereo Standard audio format
Sample Rate 44.1 kHz CD quality standard
Buffer Duration 1 second Optimal for continuous playback

Battery Impact

The framework minimizes battery usage:

  • Efficient Audio - Minimal CPU usage for audio generation
  • Smart Activation - Only active when needed
  • Automatic Cleanup - Stops immediately when not needed
  • Network Optimization - Efficient download algorithms
Battery Efficiency: In testing, background downloads with silent audio consume approximately 5-10% more battery than foreground downloads, which is comparable to other background audio apps.

Limitations and Considerations

iOS Limitations

  • App Suspension - iOS may still suspend the app after ~3 hours of background activity
  • Low Power Mode - Background activity is limited in Low Power Mode
  • Memory Pressure - iOS may terminate app if system is under memory pressure
  • User Settings - Users can disable background refresh in Settings

Best Practices

  • File Size - Use for files that take more than a few minutes to download
  • User Experience - Inform users that downloads continue in background
  • Completion Handling - Handle downloads that complete while app is backgrounded
  • Error Recovery - Implement retry logic for interrupted downloads

App Review Guidelines

When submitting to App Store:

  • Clearly explain the purpose of background audio in your app description
  • Ensure the audio background mode is legitimately used for downloads
  • Provide clear UI feedback about background download status
  • Allow users to disable background downloads if desired

Testing Background Downloads

Test Procedure

  1. Start a download in your app
  2. Press the Home button to background the app
  3. Wait a few seconds
  4. Check Console.app logs to verify download continues
  5. Return to app and verify download progress

Monitoring

Use Xcode's debug gauges to monitor:

  • CPU Usage - Should remain low during background downloads
  • Memory - Should be stable, no leaks
  • Network - Should show active network traffic
  • Energy - Monitor energy impact

Troubleshooting

Downloads Stop in Background

Problem: Downloads pause when app enters background.

Solutions:

  • Verify Background Modes capability is added
  • Check that "Audio, AirPlay, and Picture in Picture" is enabled
  • Confirm enableBackgroundAudio is set to true
  • Check device is not in Low Power Mode
  • Verify background refresh is enabled in Settings

Check Capability Programmatically

let info = manager.getBackgroundAudioCapabilityInfo()
if !info.available {
    print("Background audio not available")
    if let reason = info.reason {
        print("Reason: \(reason)")
        
        // Show alert to user
        showAlert(
            title: "Background Downloads Disabled",
            message: "Background downloads require the audio capability. \(reason)"
        )
    }
}

Audio Conflicts

Problem: Background audio interferes with app's main audio.

Solution:

// Ensure your audio session uses mixWithOthers option
let audioSession = AVAudioSession.sharedInstance()
try audioSession.setCategory(
    .playback,
    mode: .default,
    options: [.mixWithOthers]
)

// BICurlDownloader automatically uses mixWithOthers for its silent audio

Framework Logs Show Errors

If you see error messages in logs:

⚠️ Background audio mode: DISABLED
   Downloads will pause when app enters background

This means the Background Modes capability is not properly configured. Follow the setup steps above.

Complete Example

Swift

import UIKit
import BICurlDownloader

class BackgroundDownloadViewController: UIViewController {
    
    let manager = BIDownloadManager.shared
    var downloadTask: BIDownloadTask?
    
    override func viewDidLoad() {
        super.viewDidLoad()
        
        // Check background capability
        checkBackgroundCapability()
        
        // Configure manager
        var config = BIDownloadManagerConfiguration()
        config.enableLogging = true
        config.logLevel = .info
        manager.configure(config)
    }
    
    func checkBackgroundCapability() {
        let info = manager.getBackgroundAudioCapabilityInfo()
        
        if info.available {
            print("✅ Background downloads available")
        } else {
            print("❌ Background downloads NOT available")
            
            if let reason = info.reason {
                print("Reason: \(reason)")
                
                // Show alert to user
                let alert = UIAlertController(
                    title: "Background Downloads Disabled",
                    message: "To enable background downloads, please enable the Background Modes capability in your project. \(reason)",
                    preferredStyle: .alert
                )
                alert.addAction(UIAlertAction(title: "OK", style: .default))
                present(alert, animated: true)
            }
        }
    }
    
    func startBackgroundDownload() {
        let url = URL(string: "https://example.com/large-file.zip")!
        let destinationPath = NSTemporaryDirectory() + "large-file.zip"
        
        // Configure for background
        var options = BIDownloadOptions()
        options.enableBackgroundAudio = true
        options.enableMultipart = true
        options.maxConcurrentStreams = 4
        
        downloadTask = manager.download(
            url: url,
            destinationPath: destinationPath,
            options: options
        )
        downloadTask?.delegate = self
        
        print("Download started - will continue in background")
    }
}

extension BackgroundDownloadViewController: BIDownloadDelegate {
    func downloadDidStart(_ task: BIDownloadTask) {
        print("Download started")
    }
    
    func downloadDidProgress(_ task: BIDownloadTask, progress: Double) {
        print("Progress: \(Int(progress * 100))%")
    }
    
    func downloadDidComplete(_ task: BIDownloadTask, filePath: String) {
        print("Download completed: \(filePath)")
        
        // Send local notification if app is in background
        if UIApplication.shared.applicationState == .background {
            sendCompletionNotification()
        }
    }
    
    func downloadDidFail(_ task: BIDownloadTask, error: Error) {
        print("Download failed: \(error)")
    }
    
    private func sendCompletionNotification() {
        let content = UNMutableNotificationContent()
        content.title = "Download Complete"
        content.body = "Your file has been downloaded successfully"
        content.sound = .default
        
        let request = UNNotificationRequest(
            identifier: UUID().uuidString,
            content: content,
            trigger: nil
        )
        
        UNUserNotificationCenter.current().add(request)
    }
}

Objective-C

@interface BackgroundDownloadViewController () <BIDownloadDelegate>
@property (nonatomic, strong) BIDownloadTask *downloadTask;
@end

@implementation BackgroundDownloadViewController

- (void)viewDidLoad {
    [super viewDidLoad];
    
    [self checkBackgroundCapability];
    
    // Configure manager
    BIDownloadManagerConfiguration *config = [[BIDownloadManagerConfiguration alloc] init];
    config.enableLogging = YES;
    config.logLevel = BILogLevelInfo;
    [[BIDownloadManager shared] configure:config];
}

- (void)checkBackgroundCapability {
    BOOL isAvailable = [[BIDownloadManager shared] checkBackgroundAudioAvailability];
    
    if (isAvailable) {
        NSLog(@"✅ Background downloads available");
    } else {
        NSLog(@"❌ Background downloads NOT available");
        
        UIAlertController *alert = [UIAlertController
            alertControllerWithTitle:@"Background Downloads Disabled"
            message:@"To enable background downloads, please enable the Background Modes capability."
            preferredStyle:UIAlertControllerStyleAlert];
        
        [alert addAction:[UIAlertAction actionWithTitle:@"OK" style:UIAlertActionStyleDefault handler:nil]];
        [self presentViewController:alert animated:YES completion:nil];
    }
}

- (void)startBackgroundDownload {
    NSURL *url = [NSURL URLWithString:@"https://example.com/large-file.zip"];
    NSString *destinationPath = [NSTemporaryDirectory() stringByAppendingPathComponent:@"large-file.zip"];
    
    BIDownloadOptions *options = [[BIDownloadOptions alloc] init];
    options.enableBackgroundAudio = YES;
    options.enableMultipart = YES;
    options.maxConcurrentStreams = 4;
    
    BIDownloadManager *manager = [BIDownloadManager shared];
    self.downloadTask = [manager downloadFromURL:url
                                 destinationPath:destinationPath
                                         options:options];
    self.downloadTask.delegate = self;
    
    NSLog(@"Download started - will continue in background");
}

#pragma mark - BIDownloadDelegate

- (void)downloadDidStart:(BIDownloadTask *)task {
    NSLog(@"Download started");
}

- (void)downloadDidProgress:(BIDownloadTask *)task progress:(double)progress {
    NSLog(@"Progress: %ld%%", (long)(progress * 100));
}

- (void)downloadDidComplete:(BIDownloadTask *)task filePath:(NSString *)filePath {
    NSLog(@"Download completed: %@", filePath);
    
    if ([UIApplication sharedApplication].applicationState == UIApplicationStateBackground) {
        [self sendCompletionNotification];
    }
}

- (void)downloadDidFail:(BIDownloadTask *)task error:(NSError *)error {
    NSLog(@"Download failed: %@", error.localizedDescription);
}

- (void)sendCompletionNotification {
    UNMutableNotificationContent *content = [[UNMutableNotificationContent alloc] init];
    content.title = @"Download Complete";
    content.body = @"Your file has been downloaded successfully";
    content.sound = [UNNotificationSound defaultSound];
    
    UNNotificationRequest *request = [UNNotificationRequest
        requestWithIdentifier:[[NSUUID UUID] UUIDString]
        content:content
        trigger:nil];
    
    [[UNUserNotificationCenter currentNotificationCenter] addNotificationRequest:request
                                                           withCompletionHandler:nil];
}

@end
