Installation

Adding BICurlDownloader to Your Project

Requirements

Before installing BICurlDownloader, ensure your project meets these requirements:

Requirement Minimum Version
iOS Deployment Target 13.0+
Xcode 12.0+
Swift 5.0+
Objective-C Compatible

Swift Package Manager

Swift Package Manager is the recommended way to integrate BICurlDownloader.

Using Xcode

  1. Open your project in Xcode
  2. Go to File → Add Packages...
  3. Enter the repository URL: 
    https://github.com/your-repo/BICurlDownloader.git
  4. Select the version rule (e.g., "Up to Next Major" with 1.0.0)
  5. Click Add Package
  6. Select the target where you want to use BICurlDownloader
  7. Click Add Package again

Using Package.swift

Add BICurlDownloader as a dependency in your Package.swift:

dependencies: [
    .package(url: "https://github.com/your-repo/BICurlDownloader.git", from: "1.0.0")
]

Then add it to your target dependencies:

targets: [
    .target(
        name: "YourTarget",
        dependencies: ["BICurlDownloader"]
    )
]

CocoaPods

If you prefer CocoaPods, add BICurlDownloader to your Podfile:

Installation Steps

  1. If you don't have CocoaPods installed, install it: 
    $ sudo gem install cocoapods
  2. Create or open your Podfile in the project root: 
    $ pod init
  3. Add BICurlDownloader to your Podfile: 
    platform :ios, '13.0'
use_frameworks!

target 'YourApp' do
    pod 'BICurlDownloader', '~> 1.0.0'
end
  4. Install the pod: 
    $ pod install
  5. Open the generated .xcworkspace file: 
    $ open YourApp.xcworkspace
Important: Always use the .xcworkspace file after installing pods, not the .xcodeproj file.

Manual Installation

You can also manually add BICurlDownloader to your project.

Using XCFramework

  1. Download the latest release from the releases page
  2. Unzip the downloaded file
  3. In Xcode, navigate to your project settings
  4. Select your app target
  5. Go to the General tab
  6. Scroll to Frameworks, Libraries, and Embedded Content
  7. Click the + button
  8. Click Add Other... → Add Files...
  9. Navigate to and select:
    • BICurlDownloader.xcframework
    • curl.xcframework (dependency)
  10. Ensure both frameworks are set to Embed & Sign

From Source

  1. Clone the repository: 
    $ git clone https://github.com/your-repo/BICurlDownloader.git
  2. Drag the BICurlDownloader.xcodeproj into your Xcode project
  3. In your app target settings, go to General tab
  4. Add BICurlDownloader.framework to Frameworks, Libraries, and Embedded Content
  5. Set it to Embed & Sign

Importing the Framework

Swift

import BICurlDownloader

class ViewController: UIViewController {
    let manager = BIDownloadManager.shared
    
    // Your code here
}

Objective-C

@import BICurlDownloader;

@interface ViewController ()
@property (nonatomic, strong) BIDownloadManager *manager;
@end

@implementation ViewController

- (void)viewDidLoad {
    [super viewDidLoad];
    self.manager = [BIDownloadManager shared];
    
    // Your code here
}

@end

Enable Background Downloads (Optional)

To enable background downloads when the app is not in foreground, you need to add the Background Modes capability.

Steps to Enable

  1. Open your project in Xcode
  2. Select your app target
  3. Go to the Signing & Capabilities tab
  4. Click + Capability
  5. Add Background Modes
  6. Enable Audio, AirPlay, and Picture in Picture
How it works:
BICurlDownloader uses programmatically generated silent audio to keep the app active in the background, allowing downloads to continue. This is a legitimate use of the audio background mode.

Info.plist Configuration

Xcode automatically adds the required keys to your Info.plist. Verify that it includes:

<key>UIBackgroundModes</key>
<array>
    <string>audio</string>
</array>

Verify Installation

To verify that BICurlDownloader is correctly installed, try this simple test:

Swift

import BICurlDownloader

// Check framework version
print(BICurlDownloaderInfo.fullVersion)
// Output: BICurlDownloader v1.0.0 (1)

// Check if background audio is available
let manager = BIDownloadManager.shared
let isAvailable = manager.checkBackgroundAudioAvailability()
print("Background downloads available: \(isAvailable)")

Objective-C

@import BICurlDownloader;

// Check framework version
NSLog(@"%@", [BICurlDownloaderInfo fullVersion]);
// Output: BICurlDownloader v1.0.0 (1)

// Check if background audio is available
BIDownloadManager *manager = [BIDownloadManager shared];
BOOL isAvailable = [manager checkBackgroundAudioAvailability];
NSLog(@"Background downloads available: %@", isAvailable ? @"YES" : @"NO");
Installation successful!
If the code compiles and runs without errors, BICurlDownloader is correctly installed.

Installation Troubleshooting

Framework not found

Problem: Xcode cannot find the BICurlDownloader module.

Solution:

  • Clean build folder: Product → Clean Build Folder
  • Restart Xcode
  • Verify the framework is properly linked in Build Phases

Missing curl.xcframework

Problem: Linker errors related to libcurl symbols.

Solution:

  • Ensure curl.xcframework is included in your project
  • Check that it's added to "Frameworks, Libraries, and Embedded Content"
  • Verify the framework search paths are correct

Swift/Objective-C Bridging Issues

Problem: Cannot use framework in Objective-C project.

Solution:

  • Ensure you're using @import BICurlDownloader; not #import
  • Enable "Always Embed Swift Standard Libraries" in Build Settings
  • Check that your deployment target is iOS 13.0+

CocoaPods Installation Fails

Problem: pod install command fails.

Solution:

  • Update CocoaPods: $ sudo gem install cocoapods
  • Update pod repository: $ pod repo update
  • Try: $ pod install --repo-update
