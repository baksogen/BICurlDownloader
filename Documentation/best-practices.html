Best Practices

Guidelines for optimal framework usage

Performance Optimization

  • Use multipart downloads for files larger than 50 MB
  • Limit concurrent downloads to 2-4 on mobile devices
  • Adjust stream count based on network type (WiFi vs Cellular)
  • Enable background audio only when necessary
  • Clean up completed downloads to free disk space

Memory Management

  • Keep strong references to download tasks until completion
  • Remove notification observers in deinit/dealloc
  • Use weak self in closures to avoid retain cycles
  • Cancel downloads when view controllers are dismissed
class DownloadViewController: UIViewController {
    var downloadTask: BIDownloadTask?
    
    override func viewWillDisappear(_ animated: Bool) {
        super.viewWillDisappear(animated)
        if isMovingFromParent {
            downloadTask?.cancel()
        }
    }
    
    deinit {
        NotificationCenter.default.removeObserver(self)
    }
}

Error Handling

  • Always implement downloadDidFail delegate method
  • Use exponential backoff for retry logic
  • Check disk space before starting large downloads
  • Handle authentication errors gracefully
  • Provide clear error messages to users

Security

  • Always use HTTPS for downloads
  • Store credentials in Keychain, not UserDefaults
  • Validate SSL certificates (sslVerification = true)
  • Don't hardcode API keys or tokens
  • Implement token refresh for expired credentials

User Experience

  • Show progress indicators for all downloads
  • Allow users to pause/resume downloads
  • Notify users when downloads complete in background
  • Provide option to download over WiFi only
  • Show estimated time remaining when possible

Testing

  • Test with slow network conditions
  • Test interruptions (phone calls, airplane mode)
  • Test with various file sizes (small, medium, large)
  • Test authentication failures and retries
  • Test low disk space scenarios
