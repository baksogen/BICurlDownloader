Authentication

Download from protected resources

Overview

BICurlDownloader supports multiple authentication methods for downloading files from protected servers. The framework handles authentication automatically once configured.

Basic Authentication

Username and password encoded in Base64

Digest Authentication

More secure challenge-response mechanism

Bearer Token

OAuth 2.0 and JWT token support

Custom Headers

Any custom authentication header

Basic Authentication

The simplest form of HTTP authentication, using username and password.

How It Works

// Client sends credentials in Authorization header:
Authorization: Basic dXNlcm5hbWU6cGFzc3dvcmQ=

// Where "dXNlcm5hbWU6cGFzc3dvcmQ=" is Base64("username:password")

Swift Implementation

import BICurlDownloader

let auth = BIAuthenticationOptions(
    basicWithUsername: "myusername",
    password: "mypassword"
)

var options = BIDownloadOptions()
options.authentication = auth

let task = manager.download(
    url: url,
    destinationPath: path,
    options: options
)
task.delegate = self

Objective-C Implementation

@import BICurlDownloader;

BIAuthenticationOptions *auth = [[BIAuthenticationOptions alloc] 
    initWithBasicWithUsername:@"myusername" 
                     password:@"mypassword"];

BIDownloadOptions *options = [[BIDownloadOptions alloc] init];
options.authentication = auth;

BIDownloadTask *task = [manager downloadFromURL:url
                                destinationPath:path
                                        options:options];
task.delegate = self;
Security Note: Basic authentication sends credentials in Base64 encoding, which is easily decoded. Always use HTTPS (not HTTP) when using Basic authentication.

Digest Authentication

More secure than Basic authentication, using MD5 hashing and nonce values.

How It Works

  1. Client makes request without credentials
  2. Server responds with 401 and challenge (nonce)
  3. Client computes hash with username, password, and nonce
  4. Client sends hashed credentials
  5. Server validates and grants access

Swift Implementation

let auth = BIAuthenticationOptions(
    digestWithUsername: "myusername",
    password: "mypassword"
)

var options = BIDownloadOptions()
options.authentication = auth

let task = manager.download(
    url: url,
    destinationPath: path,
    options: options
)

Objective-C Implementation

BIAuthenticationOptions *auth = [[BIAuthenticationOptions alloc] 
    initWithDigestWithUsername:@"myusername" 
                      password:@"mypassword"];

BIDownloadOptions *options = [[BIDownloadOptions alloc] init];
options.authentication = auth;

BIDownloadTask *task = [manager downloadFromURL:url
                                destinationPath:path
                                        options:options];
Advantage: Digest authentication never sends the password in plain text or Base64. The password is hashed before transmission.

Bearer Token Authentication

Used with OAuth 2.0, JWT tokens, and modern API authentication.

How It Works

// Client sends token in Authorization header:
Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...

Token Refresh Example

// Swift
class TokenManager {
    var currentToken: String?
    var tokenExpiry: Date?
    
    func getValidToken() -> String? {
        // Check if token is expired
        if let expiry = tokenExpiry, Date() > expiry {
            // Token expired, refresh it
            refreshToken { newToken in
                self.currentToken = newToken
                self.tokenExpiry = Date().addingTimeInterval(3600) // 1 hour
            }
        }
        return currentToken
    }
    
    func refreshToken(completion: @escaping (String) -> Void) {
        // Call your API to refresh token
        // This is pseudo-code
        APIClient.refreshToken { result in
            switch result {
            case .success(let newToken):
                completion(newToken)
            case .failure(let error):
                print("Token refresh failed: \(error)")
            }
        }
    }
}

// Usage
let tokenManager = TokenManager()

func downloadWithFreshToken() {
    guard let token = tokenManager.getValidToken() else {
        print("No valid token")
        return
    }
    
    let auth = BIAuthenticationOptions(bearerToken: token)
    var options = BIDownloadOptions()
    options.authentication = auth
    
    let task = manager.download(url: url, destinationPath: path, options: options)
    task.delegate = self
}

Additional Custom Headers

Beyond authentication, you can add any custom HTTP headers.

Swift Implementation

var options = BIDownloadOptions()

// Add authentication
options.authentication = BIAuthenticationOptions(
    bearerToken: "your_token"

Secure Credential Storage

Best practices for storing authentication credentials securely.

Using Keychain

import Security

class KeychainHelper {
    
    static func saveCredentials(username: String, password: String, server: String) {
        let query: [String: Any] = [
            kSecClass as String: kSecClassInternetPassword,
            kSecAttrAccount as String: username,
            kSecAttrServer as String: server,
            kSecValueData as String: password.data(using: .utf8)!
        ]
        
        SecItemDelete(query as CFDictionary)
        SecItemAdd(query as CFDictionary, nil)
    }
    
    static func retrieveCredentials(username: String, server: String) -> String? {
        let query: [String: Any] = [
            kSecClass as String: kSecClassInternetPassword,
            kSecAttrAccount as String: username,
            kSecAttrServer as String: server,
            kSecReturnData as String: true
        ]
        
        var result: AnyObject?
        let status = SecItemCopyMatching(query as CFDictionary, &result)
        
        if status == errSecSuccess,
           let data = result as? Data,
           let password = String(data: data, encoding: .utf8) {
            return password
        }
        
        return nil
    }
    
    static func deleteCredentials(username: String, server: String) {
        let query: [String: Any] = [
            kSecClass as String: kSecClassInternetPassword,
            kSecAttrAccount as String: username,
            kSecAttrServer as String: server
        ]
        
        SecItemDelete(query as CFDictionary)
    }
}

// Usage
KeychainHelper.saveCredentials(
    username: "user@example.com",
    password: "secretPassword",
    server: "api.example.com"
)

// Retrieve and use
if let password = KeychainHelper.retrieveCredentials(
    username: "user@example.com",
    server: "api.example.com"
) {
    let auth = BIAuthenticationOptions(
        basicWithUsername: "user@example.com",
        password: password
    )
    // Use auth for download
}
Security Best Practice: Never hardcode credentials in your app. Always use Keychain for storing sensitive information like passwords and tokens.

Authentication Error Handling

Common Authentication Errors

HTTP Status Meaning Action
401 Unauthorized Invalid or missing credentials Check credentials, refresh token
403 Forbidden Valid credentials but no access Check permissions
407 Proxy Auth Required Proxy authentication needed Configure proxy credentials

Swift Implementation

func downloadDidFail(_ task: BIDownloadTask, error: Error) {
    let nsError = error as NSError
    
    if nsError.code == BIDownloadErrorCode.authenticationError.rawValue {
        print("Authentication failed")
        
        // Try to refresh token
        if let tokenManager = self.tokenManager {
            tokenManager.refreshToken { [weak self] newToken in
                guard let self = self else { return }
                
                // Retry download with new token
                let auth = BIAuthenticationOptions(bearerToken: newToken)
                var options = BIDownloadOptions()
                options.authentication = auth
                
                let newTask = self.manager.download(
                    url: task.url,
                    destinationPath: task.destinationPath,
                    options: options
                )
                newTask.delegate = self
            }
        } else {
            // Show login screen
            showLoginScreen()
        }
    } else if nsError.code == BIDownloadErrorCode.serverError.rawValue {
        // Check if it's 401 or 403
        if let userInfo = nsError.userInfo as? [String: Any],
           let serverCode = userInfo["ServerCode"] as? Int {
            
            switch serverCode {
            case 401:
                print("Unauthorized - invalid credentials")
                showLoginScreen()
                
            case 403:
                print("Forbidden - insufficient permissions")
                showAccessDeniedAlert()
                
            default:
                print("Server error: \(serverCode)")
            }
        }
    }
}

Objective-C Implementation

- (void)downloadDidFail:(BIDownloadTask *)task error:(NSError *)error {
    if (error.code == BIDownloadErrorCodeAuthenticationError) {
        NSLog(@"Authentication failed");
        
        // Show login screen
        [self showLoginScreen];
        
    } else if (error.code == BIDownloadErrorCodeServerError) {
        // Check HTTP status code
        NSNumber *serverCode = error.userInfo[@"ServerCode"];
        
        if ([serverCode integerValue] == 401) {
            NSLog(@"Unauthorized - invalid credentials");
            [self showLoginScreen];
            
        } else if ([serverCode integerValue] == 403) {
            NSLog(@"Forbidden - insufficient permissions");
            [self showAccessDeniedAlert];
        }
    }
}

Example 4: OAuth 2.0 Flow

// Swift
class OAuth2Manager {
    var accessToken: String?
    var refreshToken: String?
    var tokenExpiry: Date?
    
    func downloadWithOAuth(fileURL: URL, completion: @escaping (Result) -> Void) {
        ensureValidToken { [weak self] token in
            guard let self = self, let token = token else {
                completion(.failure(NSError(domain: "OAuth", code: 401, userInfo: nil)))
                return
            }
            
            let auth = BIAuthenticationOptions(bearerToken: token)
            var options = BIDownloadOptions()
            options.authentication = auth
            
            let task = BIDownloadManager.shared.download(
                url: fileURL,
                destinationPath: "/path/to/destination",
                options: options
            )
            
            // Store completion for later
            self.pendingCompletion = completion
            task.delegate = self
        }
    }
    
    func ensureValidToken(completion: @escaping (String?) -> Void) {
        // Check if token is valid
        if let token = accessToken,
           let expiry = tokenExpiry,
           Date() < expiry {
            completion(token)
            return
        }
        
        // Token expired, refresh it
        refreshAccessToken { newToken in
            completion(newToken)
        }
    }
    
    func refreshAccessToken(completion: @escaping (String?) -> Void) {
        guard let refreshToken = refreshToken else {
            // No refresh token, need to re-authenticate
            completion(nil)
            return
        }
        
        // Call OAuth server to refresh token
        // This is pseudo-code
        OAuthClient.refreshToken(refreshToken) { result in
            switch result {
            case .success(let response):
                self.accessToken = response.accessToken
                self.refreshToken = response.refreshToken
                self.tokenExpiry = Date().addingTimeInterval(TimeInterval(response.expiresIn))
                completion(response.accessToken)
                
            case .failure:
                completion(nil)
            }
        }
    }
}
