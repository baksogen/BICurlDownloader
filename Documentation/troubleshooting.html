Troubleshooting

Common issues and solutions

Downloads Stop in Background

Problem: Downloads pause when app enters background.

Solutions:

  • Verify Background Modes capability is enabled
  • Check "Audio, AirPlay, and Picture in Picture" is selected
  • Ensure enableBackgroundAudio = true in options
  • Check device is not in Low Power Mode
  • Verify background refresh is enabled in Settings
// Check capability
let isAvailable = BIDownloadManager.shared.checkBackgroundAudioAvailability()
if !isAvailable {
    print("Background downloads not available")
}

Slow Download Speed

Problem: Downloads are slower than expected.

Solutions:

  • Increase concurrent streams: maxConcurrentStreams = 8
  • Check if server supports Range requests
  • Verify network connection quality
  • Reduce number of concurrent downloads
  • Check if server is throttling connections

Authentication Fails

Problem: Getting 401 or 403 errors.

Solutions:

  • Verify credentials are correct
  • Check authentication type matches server requirements
  • Refresh expired tokens
  • Ensure proper headers are sent
// Enable logging to see requests
var config = BIDownloadManagerConfiguration()
config.enableLogging = true
config.logLevel = .verbose
BIDownloadManager.shared.configure(config)

Multipart Download Not Active

Problem: Files download in single thread mode.

Possible Causes:

  • Server doesn't support Range requests
  • File size is less than 5 MB
  • Content-Length header is missing
  • enableMultipart = false in options

Check:

// Test server support
curl -I https://your-server.com/file.zip
// Look for: Accept-Ranges: bytes

Memory Warnings or Crashes

Problem: App receives memory warnings during downloads.

Solutions:

  • Reduce maxConcurrentDownloads
  • Reduce maxConcurrentStreams
  • Cancel unused downloads
  • Remove strong references to completed tasks

Downloaded Files Are Incomplete

Problem: Files download but are corrupted or incomplete.

Solutions:

  • Check available disk space
  • Verify server sends correct Content-Length
  • Try disabling multipart: enableMultipart = false
  • Check network stability

Enable Debug Logging

For any issue, enable verbose logging first:

var config = BIDownloadManagerConfiguration()
config.enableLogging = true
config.logLevel = .verbose
BIDownloadManager.shared.configure(config)

// Check Console.app or Xcode console for detailed logs

FAQ

Q: Can I download to iCloud Drive?

A: Yes, use the iCloud container path as destination.

Q: Does it work with cellular data?

A: Yes, set allowsCellularAccess = true.

Q: Can I download multiple files simultaneously?

A: Yes, configure maxConcurrentDownloads in configuration.

Q: How do I resume a failed download?

A: Simply call download() again with the same URL and path.

Q: Does it support proxy servers?

A: Yes, cURL respects system proxy settings automatically.

Getting Help

If you're still experiencing issues:

  • Check this documentation thoroughly
  • Enable verbose logging and examine output
  • Search for similar issues on GitHub
  • Create a detailed issue report with:
    • iOS version
    • Framework version
    • Complete error logs
    • Minimal reproducible code
    • Expected vs actual behavior
Support: For bugs and feature requests, please open an issue on GitHub with detailed information.
